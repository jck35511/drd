# 멍랜디 0.30.0 적용 및 검증 기록

## 적용 기능
- 일반 소환 20G는 소환 보관함에 누적됩니다. 필드가 가득 차도 소환할 수 있습니다. 보관함에서 유닛 선택 후 빈 6×6 필드 칸을 누르면 배치합니다. 보관 중에는 전투하지 않으며 조합은 필드 재료를 사용합니다.
- 시작 화면, 이어하기, 승리/패배 결과, 난이도 선택부터 다시하기.
- 뽑기 결과 팝업 2.8초 표시 후 사라짐. 최근 20회 기록에 결과와 천장 보상 유지.
- 맹수/신화/초월 비용 50/100/200G. 각 아이템 확률 1%/0.1%/0.01%.
- 모든 뽑기에서 히든 선택권 0.001%, 골드 0배 70%. 나머지는 1~10배의 감소하는 확률로 분배. 단일 1,000,000개 정수 티켓 표로 합계 정확히 100%. 골드는 해당 뽑기 비용 × 배율.
- 유형별 100·200·300회마다 해당 조합 아이템 선택권 추가 지급. 일반 아이템 당첨으로 횟수가 초기화되지 않음.
- 히든 선택권은 아스테리온·녹티르·루미엘 중 하나 선택하여 보관함 지급. 각기 별빛 폭발/균열 지속 피해/아군 공명 강화, 별도 그림·공격 프레임·효과음.
- 보관함, 선택권, 천장, 전투 상태는 이어하기로 복원. 다시하기는 해당 판 상태 초기화.

## 승인 후 적용한 밸런스 1차 패치
- 20G 소환, 일반 적 처치 5G, 기존 49종 능력치 유지.
- 일반 80라운드 골드: 2,250 → 1,370G.
- 보스 8회 골드: 7,100 → 2,950G.
- 최초 조합: 맹수 400 → 100G, 신화 1,000 → 250G, 초월 종류별 2,000 → 500G. 전체 최초 조합 합계 7,400 → 1,850G.
- 시작 골드·모든 적 처치·모든 보상 합계의 이론상 총공급: 24,050 → 13,470G. 판매·뽑기 반환 및 선택권의 가치는 제외. 마지막 보스 700G는 승리 후 지급되므로 클리어 자금에 포함하면 안 됨.
- 골드 급증 대신 난이도별 고정 라운드 조합 아이템 선택권을 지급. 전체 횟수는 쉬움 13/5/1, 보통 11/5/1, 어려움 10/5/1, 지옥 2/1/0 (맹수/신화/초월 순). 이는 유닛 자체가 아니라 재료 아이템이며 조합 유닛은 따로 필요.
- 쉬움·보통 적 체력/방어 완화. 보스 추가 체력 증가는 60·70·80라운드에 집중.
- 지옥은 고정 초월 아이템 선택권 라운드 보상이 없음. 유료 뽑기 100회 천장은 지옥에서도 동일하게 적용.

| 보통 | 0/8 | 8/8 | 80라운드 승리 |

별도 완성 덱 최종 보스 시험은 전력 예산만 확인하는 시험입니다. 이 덱을 실제 플레이에서 얻을 수 있다는 증거로 사용하지 않습니다.
- 초월 1 + 신화 3 + 지원 4 구성: 쉬움 4/4, 보통 4/4, 어려움 4/4, 지옥 2/4.
- 지옥의 같은 구성은 시드에 따라 제한 시간 내 성공/실패가 갈렸습니다.
- 두 초월 중심/세 초월 중심 완성 덱의 최종 보스 시험도 수행했으며 원시 결과는 JSON에 기록했습니다.

**해석 한계:** 위 숫자는 사람의 승률이 아닙니다. 자동 재배치는 실제 손 조작과 다릅니다. 쉬움·보통의 전체 진행은 확인했지만, 어려움·지옥의 획득 경제까지 포함한 전체 클리어 및 사람의 '완벽한 숙련도' 요구 수준은 아직 입증되지 않았습니다. 보통의 기본 전략 0/8도 실제 플레이 체감으로 재검토해야 합니다. 실기기 성능·장시간 발열은 에뮬레이터 결과로 대신할 수 없습니다.
