# 멍랜디 0.31.0

[APK 직접 다운로드](https://github.com/jck35511/drd/releases/download/v0.31.0/MeongRandy-0.31.0-debug.apk) · [릴리스와 실행 화면](https://github.com/jck35511/drd/releases/tag/v0.31.0)

## 화면
사용자가 승인한 모바일용 시작·승리·패배 원본 PNG 3장을 그대로 사용합니다. 그림 비율을 유지하며 터치 영역을 그림의 버튼에 맞춥니다. 결과 패널의 예시 수치와 시안 캡션만 실제 게임 UI로 교체합니다.
- 게임 시작 → 난이도 선택. 이어하기는 저장된 게임이 있을 때 활성화.
- 조합 도감·설정은 시작 화면에서도 열 수 있습니다.
- 승패 화면은 실제 난이도, 도달 라운드, 격파한 보스 수를 표시합니다.
- 다시하기 → 새 난이도 선택. 시작 화면 → 타이틀 복귀.

## 보관함과 조합
- 전체 52종을 보관·배치·회수할 수 있습니다. 필드에서 유닛 선택 → 소환 보관함 → 선택 유닛의 보관함 이동 버튼.
- 회수 시 공격 대기시간과 히든 충전 등 개별 전투 상태를 보존합니다. 보관 중에는 전투하지 않습니다.
- 조합은 필드와 보관함의 재료를 합산합니다. 필드 재료를 우선 사용하며, 선택 유닛 조합은 해당 유닛의 칸을 유지합니다.
- 모든 조합 결과는 즉시 필드에 등장합니다. 보관함 재료만 사용하면 빈 칸에 배치합니다. 필드가 가득 차고 사용할 필드 재료도 없으면 재료·아이템을 소모하지 않습니다.
- 중복 재료, 아이템 부족, 반복 클릭, 저장·복원을 검증했습니다.

## 도감과 보상
- 소형견 → 중형견 → 대형견 → 맹수 → 신화 → 초월 → 히든 순서.
- ‘전체 39종’ 필터를 제거하고 소형견 10종과 히든 3종의 획득 안내를 추가했습니다. 기존 조합식 39개는 유지합니다.
- 라운드별 조합 아이템 선택권 지급을 제거했습니다. 뽑기별 100회 반복 천장은 유지합니다.
- 0.30.0의 골드·전투 수치는 추가 변경하지 않았습니다. 이전 저장에 이미 지급된 선택권은 보존합니다.
