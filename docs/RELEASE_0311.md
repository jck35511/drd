# 멍랜디 0.31.1

- Godot 기본 시작 로고를 시작 화면과 같은 분위기의 그림과 멍랜디 제목만 있는 로딩 이미지로 교체했습니다. 버튼, 디자인 시안 문구, 인위적인 대기 시간은 없습니다.
- 소환 보관함 각 행에서 배치 옆의 판매 버튼으로 유닛 한 마리를 판매합니다.
- 기존 필드 판매 가격을 그대로 사용합니다: 소형견 10G, 중형견 40G, 대형견 100G. 맹수·신화·초월·히든은 판매 불가입니다.
- 판매는 개별 보관 상태를 함께 제거하고, 골드와 남은 수량을 저장합니다. 마지막 유닛을 팔면 해당 유닛의 배치 대기도 해제됩니다.
