# 멍랜디 — 천공 성채
원본: jck35511/drd @ 061e5e3f798bd914673d24e6f7f84125557a5b54

## 실행
Godot 4.5.1에서 project.godot을 열고 F5.
Android APK는 GitHub Actions의 MeongRandy-Step29-Android-and-source 아티팩트에 생성됩니다.
debug 서명은 설치 테스트용이며 스토어 배포용 소유자 서명이 아닙니다.

## 유지한 규칙
6×6 필드, 49종 명단, 39개 조합, 소환 20G, 전용 뽑기 50G,
맹수 각 3% / 신화 각 1% / 초월 각 0.1%, 기존 골드 환급 확률,
80 일반 웨이브 + 보스 8회, 4난이도 수치.
지옥은 숙련된 운영과 좋은 운이 모두 필요하도록 설계된 난이도입니다.

## 수정
- 49종 독립 캐릭터 그림, 일반 적 4종 외형, 보스 8종 외형.
- 천공 성채 배경과 정확한 6×6 석재 필드.
- 적은 enemy_type과 boss_round로 외형을 선택.
- 출혈/중독은 물리 방어, 화상은 마법 저항 적용.
- 방어 약화는 저항 수치만 낮추며 별도 피해 증폭을 중복 적용하지 않음.
- 보스 기절/빙결 지속 시간 50%.
- 일반견 조합의 기본 DPS는 재료들의 합계 이상. 상위 등급 공격력과 후반 성장 배율은 유지.
- 중앙 4칸은 지원/재료용으로 표시. 일반 소환은 공격 가능한 빈 칸 우선.
- 사거리 원과 실제 타격 가능한 경로 표시. 화면 공격력에 웨이브 배율/오라 반영.
- 60Hz 고정 전투 스텝으로 FPS/배속과 전투 결과 분리.
- 공격 동작/투사체/상태이상/신화·초월 전용 색과 연출, 동시 이펙트 96개 제한.
- 일시정지, 앱 백그라운드 전환 시 정지, 10초 간격 저장 및 복귀 시 일시정지 상태로 복원.
- 세로 비율 유지, 큰 터치 버튼, 오프라인 동작.

### 난이도 표본
정상 게임 행동만 사용하는 자동 운영 두 종류를 각 난이도에서 8개 시드로 실행했습니다.
아래 수치는 제한된 자동 전략의 결과이며, 사람의 승률이나 클리어 불가능 판정이 아닙니다.

| 난이도 | 소환 우선 클리어 | 시작 뽑기 우선 클리어 | 소환 우선 도달 일반 웨이브 |
|---|---:|---:|---:|
| 쉬움 | 3/8 | 0/8 | 70–80 |
| 보통 | 0/8 | 0/8 | 60–80 |
| 어려움 | 0/8 | 0/8 | 50–60 |
| 지옥 | 0/8 | 0/8 | 5–40 |

별도의 강한 유닛 사전 배치 실험은 4난이도 모두 80 일반 웨이브와 보스 8회를 종료했습니다.
이는 라운드 진행과 전투 엔진의 지속 실행 검증이며, 정상 경제로 그 유닛을 획득할 수 있다는 증거가 아닙니다.
보통·어려움·지옥의 정상 플레이 완주와 사람 기준 난이도 적정성은 아직 검증 완료로 볼 수 없습니다.
지옥의 난이도/확률을 낮추거나 보장 획득을 추가하지 않았습니다.
